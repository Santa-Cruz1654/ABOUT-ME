## About

I'm an **AI Engineer** interested in building useful, reliable systems
around large language models --- from structured outputs and
retrieval-augmented generation to stateful agent workflows and inference
services.

I learn by building: understanding the system's behavior, making design
trade-offs explicit, and turning concepts into working projects that can
be explored and tested. I also care about the security of AI
applications and bring an additional perspective from cybersecurity,
cloud security, and cyber-physical systems.

**What I'm focused on** - **LLM application engineering:** structured
outputs, RAG, context assembly, and evaluation. - **Agentic workflows:**
state, control flow, tool boundaries, and predictable failure
handling. - **Inference infrastructure:** provider abstraction, API
design, and the engineering around model calls. - **Security-aware AI:**
guardrails, prompt-injection risks, and responsible system boundaries. -
**Systems fundamentals:** distributed systems, backend design, and
reproducible engineering.

> I care about more than getting a model response. I want to understand
> and engineer the system around it.
